A hands-on learning project focused on understanding and applying the four pillars of Object-Oriented Programming (OOP) through practical exercises and experimentation.

## About the Project

This lab was created to explore the fundamentals of OOP and understand how its core principles can be applied to real programming problems.

Rather than simply learning definitions, the goal is to put these concepts into practice, understand how they work, and discover how they contribute to writing more organized, reusable, and maintainable code.

## Core Concepts

This laboratory focuses on the four pillars of Object-Oriented Programming:

- **Encapsulation** — Protecting an object's internal state and controlling access to its data.
- **Abstraction** — Hiding unnecessary implementation details and exposing essential functionality.
- **Inheritance** — Creating relationships between classes and reusing existing behavior.
- **Polymorphism** — Allowing objects to respond differently to the same method or interface.

## Learning Goals

- Understand the purpose of each OOP principle.
- Apply the four pillars through practical coding exercises.
- Explore relationships between classes and objects.
- Improve code organization, reusability, and maintainability.
- Develop problem-solving skills and strengthen programming fundamentals.
